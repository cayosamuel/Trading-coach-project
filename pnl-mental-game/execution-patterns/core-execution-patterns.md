# Core Execution Patterns

## Recognition vs Execution

A bad trading result does not automatically mean setup recognition was wrong.

Keep these separate:

1. Setup recognition
2. Confidence in the recognized setup
3. Entry execution
4. Response to normal opposing movement
5. Exit / hold decision
6. Emotion after exit
7. Re-entry / direction flip / pair switch

The review should identify the FIRST point where the process broke.

## Multiple Tickets vs Overtrading

Multiple tickets can still represent one planned recognition decision expressed with more size.

Multiple entries are not automatically overtrading.

The problem begins when additional entries are caused by:

- fear
- anger
- frustration
- repeated premature exits
- direction flips
- pair-hopping
- trying to repair an emotional mistake

## Direction Flips

Selling, losing confidence, then buying the same market is not the same thing as scaling one thesis.

Direction flips are evidence that the original recognition decision or confidence in that decision has become unstable.

## Fear -> Exit -> Anger -> Re-entry

A recurring execution loop is:

1. Recognize a setup
2. Enter
3. Small opposing movement appears
4. Fear increases
5. Exit early
6. Price remains inside the original template
7. Anger / frustration appears
8. Re-enter
9. Repeat

The solution is not to remove emotion first.

The solution is to prevent emotion from becoming the decision-maker.

## Pair-Hopping

When confidence in one valid setup drops, switching to another market can create additional damage.

After selecting the best valid candidate, do not abandon it merely because confidence becomes uncomfortable.

A new market requires a new valid WHEN / WHERE / WHAT decision.

## WHEN / WHERE / WHAT Anti-Emotion Gate

Before every:

- new order
- re-entry
- direction flip
- pair switch
- chase attempt

ask:

### WHEN
Am I inside the permitted decision window?

### WHERE
Am I at or very close to a meaningful strike reference?

Examples:
- 00
- 50
- 25
- 75
- relevant closing-price level
- appropriate prior-day high/low
- explicitly taught HOD/LOD context

If WHERE is missing, price is in no-man's-land.

### WHAT
Is the actual red-car BUY or SELL template present?

If one of the three fails, there is no trade.

## Core Mental Rule

Emotion can be high.

Process still has authority.
