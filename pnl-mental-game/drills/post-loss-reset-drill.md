# Post-Loss Reset Drill

Use this immediately after:

- a loss
- a premature exit
- a missed move
- a strong emotional spike

## 1. State What Just Happened

Describe the event without using P/L to decide whether the setup was valid.

Example questions:

- Did I recognize the setup correctly?
- Did I execute it correctly?
- Did I exit because the setup invalidated, or because emotion increased?

## 2. Check the Original Thesis

Was the original directional thesis actually invalidated?

Do not assume:

LOSS = WRONG SETUP

Do not assume:

DISCOMFORT = INVALIDATION

## 3. Before Any New Order, Reset

Before:

- re-entry
- direction flip
- pair switch
- chase

ask again:

### WHEN
Am I inside the permitted decision window?

### WHERE
Am I at a meaningful taught strike reference?

### WHAT
Is the actual red-car BUY or SELL template present?

## 4. Final Rule

If WHEN, WHERE, or WHAT is unclear:

NO TRADE.

Do not let the previous trade choose the next trade.

Emotion can still be high.

Process still has authority.
