## Core Principle

Recognition and execution are reviewed separately.

A losing result does not automatically mean setup recognition was wrong.

The review process looks for the FIRST break in the chain:

recognition
-> confidence
-> entry
-> response to opposing movement
-> hold / exit
-> emotion
-> re-entry / direction flip / pair switch

Before any new order, re-entry, direction flip, pair switch, or chase:

WHEN
-> WHERE
-> WHAT

If one fails, there is no trade.
