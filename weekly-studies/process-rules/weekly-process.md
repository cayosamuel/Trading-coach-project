# Weekly Process

## Primary Weekly Reference

Friday range is the primary weekly reference.

## Initial Balance Validation

If a market has already broken Friday range and the week is not finished, the breakout is validated only if price CLOSES outside the combined Monday + Tuesday range.

The combined Monday + Tuesday range is the Initial Balance of the week.

## Thursday Nuance

Thursday can close inside Wednesday and still remain a valid weekly breakout close if it is still closing outside the Monday + Tuesday Initial Balance.

## Signal vs Template vs Setup

Keep these separate:

1. Weekly signal / validated breakout
2. Recognizable full-week template
3. Executable intraday setup

A valid weekly signal does not automatically mean the week has built a recognizable Stacey template.

A valid weekly signal or weekly template does not automatically mean the day has produced an executable BUY or SELL setup.

## Closing Price First

Focus on closing price, not exciting intraday movement.

A market can move outside Friday range during the day and still be disqualified if it comes back and closes inside Friday range.

## Rinse and Repeat

At the start of the next week, repeat the same process using the new Friday range and the new Monday + Tuesday Initial Balance.

## Current Process Priority

The user's current weekly process and timing rules override older course timestamps or interpretations when they conflict.
