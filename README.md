# Trading Coach Project

This repository stores public-safe derived trading-study material used to build and maintain a custom trading coach.

## Public Source Families

- `visual-atlas/` — confirmed valid setups, invalid look-alikes, contrast drills, and visual-study captions
- `weekly-studies/` — weekly-process rules, full-week studies, catalogue PDFs, and supporting visuals
- `pnl-mental-game/` — execution reviews, mental-game patterns, behavioral rules, and drills
- `source-index/` — provenance, source mapping, audit notes, and retrieval/navigation references

## Master Architecture

The project is maintained through five master families:

1. Canonical Visual Atlas
2. Stacey Core Curriculum
3. Weekly Process + Catalogue
4. P&L + Mental Game
5. Project Source Index / Retrieval Map

The public repository contains the maintainable public-safe source layer for these systems where appropriate.

Generated master files are packaging artifacts built from those source materials.

## Private Source Boundary

Original Stacey Burke course PDFs and other copyrighted source material are NOT stored in this public repository.

Those originals remain private and are used only to create derived study material and compact master references.

Raw broker statements, account identifiers, and other private trading records also remain outside the public repository.

## Maintenance Principle

Public Markdown, PDF, and visual study files are treated as maintainable source material.

Collapsed master documents are rebuilt from those sources rather than manually edited as the primary source of truth.
