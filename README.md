# Trading Coach Project

This repository stores derived trading-study material used to build and maintain a custom trading coach.

## Structure

- `visual-atlas/` — confirmed valid setups, invalid look-alikes, and pre-strike captions
- `weekly-studies/` — Friday range, Initial Balance, and full-week reviews
- `pnl-mental-game/` — P&L reviews, execution mistakes, and mental-game patterns
- `source-index/` — source references, Stacey Burke YouTube links, and curriculum indexes

## Important

Original Stacey Burke course PDFs and other copyrighted source material are NOT stored in this public repository.

Those originals remain in a private local archive and are used only to create derived study material and compact GPT master files.
