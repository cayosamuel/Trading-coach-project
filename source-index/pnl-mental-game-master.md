## Purpose

Master File 4 is a derived, collapsed text master for:

- execution review
- mental-game patterns
- weekly case studies
- behavioral rules
- targeted drills

## Public Source Layer

The canonical public-safe inputs live under:

`pnl-mental-game/`

These source files are the maintainable inputs used to rebuild the collapsed master.

## Build Order

The collapsed master is assembled in a deliberate reading order controlled by a private manifest.

The generated master is a packaging artifact.

The public Markdown source files remain the canonical maintainable inputs.

## Privacy Boundary

Raw broker statements, account identifiers, and other private trading records are not published here.

Only public-safe derived summaries and behavioral lessons are stored in the repository.

## Recognition vs Execution

Technical setup recognition and execution quality are intentionally reviewed separately.

A losing result does not automatically mean setup recognition was wrong.

Execution review focuses on the first break in the process chain rather than judging validity from P&L alone.
